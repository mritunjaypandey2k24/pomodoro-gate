# GATE Chrono - Jetpack Compose Android App

Gamified Deep Focus Pomodoro Timer & RPG Leveling App for GATE exam preparation.

## Quick Start to Generate .APK:

### 1. Open in Android Studio
1. Launch **Android Studio** (Hedgehog, Iguana, Jellyfish, or newer).
2. Select **File > Open...** and choose this `android/` directory.
3. Allow Gradle to sync dependencies.

### 2. Build the Debug .APK
From the top menu bar in Android Studio:
- Select **Build > Build Bundle(s) / APK(s) > Build APK(s)**
- When compilation finishes, click **locate** in the popup notification to find:
  `app/build/outputs/apk/debug/app-debug.apk`

### 3. Install on Phone
- Transfer `app-debug.apk` to your Android device via USB cable, Google Drive, or WhatsApp.
- Tap the `.apk` file on your phone and select **Install**.
